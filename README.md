# Stellatown-PRT
A conversion of the Bombardier Innovia APM 100 on Roblox into a Personal Rapid Transit system similar to the Morgantown PRT
<img width="820" height="495" alt="Screenshot 2026-11-12 at 9 00 20 PM" src="https://github.com/user-attachments/assets/21e6461e-84cc-46e2-9b8b-7be7cf7df64d" />
Game link: https://www.roblox.com/games/118573392857400/Stellatown-PRT


A copy of the Roblox Studio Place File has been provided in the releases for users that are unable to access the game on Roblox.
To use the studio file, you first have to install Roblox Studio, then open the file by double clicking on it in your file manager.
